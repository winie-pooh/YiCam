# План тесту 0.2.0 (керування)

Після кожної частини натисни Share log і надішли лог.

1. Підключись, відкрий Пряму трансляцію. Перевір: є Відео/Фото (поточне виділене) і слайдер зуму.
2. Режим Відео: "Почати запис", почекай 5 с, "Зупинити запис". Перевір: камера справді пише; з'являється "Збережено: ...mp4"; кнопка повертається в "Почати запис".
3. Натисни Фото. Перевір: камера перемкнула режим. "Зробити фото": знімок зроблено (звук затвора, файл є).
4. Режим Фото: обери Таймлапс, "Зробити фото", дочекайся 2 кадрів, "Зупинити таймлапс". Перевір: зупинилось. Напиши, який текст був на кнопці.
5. Обери Серія, потім Таймер, кожного разу "Зробити фото". Напиши, що зробила камера.
6. Рухай слайдер зуму повільно і швидко. Перевір: картинка зумиться, додаток не зависає. Напиши робочий діапазон.
7. Натисни фізичну кнопку на камері (запис), поки додаток відкритий. Перевір: кнопка в додатку стає "Зупинити запис" приблизно за 1 с.
8. Зайди в Probe, натисни "Options" (при підключенні). Share log. Це потрібно для 0.3.0.
