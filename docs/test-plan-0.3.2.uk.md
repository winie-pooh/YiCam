# План тесту 0.3.2

1. Налаштування камери: значення мають бути перекладені (Світлові індикатори: "Усі увімкнено" тощо). Під "Стандарт відео" є пояснення.
2. Відкрий Пряму трансляцію, вийди, відкрий Налаштування: сірі рядки і кнопка "Розблокувати". Натисни її: рядки стають активними, стандарт можна змінити.
3. Disconnect. Вимкни Wi-Fi камери в телефоні (або перемкнись на домашню мережу). Натисни "Обрати Wi-Fi мережу і підключитись": має відкритись системний список Wi-Fi. Обери мережу камери і закрий список: додаток має підключитись сам.
4. Share log.
