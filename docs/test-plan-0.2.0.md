# Test plan 0.2.0 (controls)

Copy the log with Share log after each part and send it.

1. Connect, open Live view. Check: the panel shows Video/Photo (current one highlighted) and a zoom slider.
2. Video mode: press "Start recording", wait 5 s, press "Stop recording". Check: the camera really records; a "Saved: ...mp4" note appears; the button returns to "Start recording".
3. Press Photo. Check: the camera switches mode. Press "Take photo". Check: a photo is taken (shutter sound, file appears).
4. Photo mode: choose Time-lapse, press "Take photo", wait for 2 shots, press "Stop time-lapse". Check: it stops. Report which button text was shown.
5. Choose Burst, then Timer, press "Take photo" each time. Report what the camera did.
6. Move the zoom slider slowly and quickly. Check: the picture zooms, the app does not freeze. Report the range that works.
7. Press the physical camera button while the app is open (record). Check: the app button changes to "Stop recording" within about 1 s.
8. Press Probe, then "Options" (connected). Share log. This is needed for 0.3.0.

If something fails: note which step and what the screen showed.
