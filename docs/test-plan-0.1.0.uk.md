# Тест-план 0.1.0 — пряма трансляція (live view)

Для того, хто тестує на телефоні, і для ШІ, який читає звіт. Це український переклад файлу `test-plan-0.1.0.md`; якщо вони розійдуться, головним є англійський оригінал.
Автор не компілював і не запускав код 0.1.0 (там, де його писали, немає компілятора Kotlin): спершу виконайте `./gradlew testDebugUnitTest`.

## Підготовка (один раз)
1. У `app/build.gradle.kts` у блок `dependencies { ... }` додайте:
   `implementation("androidx.media3:media3-exoplayer:1.8.0")`
   `implementation("androidx.media3:media3-exoplayer-rtsp:1.8.0")`
   Синхронізуйте Gradle. (Версія 1.8.0 точно існує; можна взяти новішу 1.x.)
2. У `AndroidManifest.xml` у тег `<activity ...>` додайте атрибут
   `android:configChanges="orientation|screenSize|smallestScreenSize|screenLayout|keyboardHidden"`,
   щоб поворот екрана не перезапускав відео.
3. Розпакуйте файли 0.1.0 поверх проєкту, запустіть юніт-тести, потім запустіть застосунок.

## Якщо картинка не з'являється
1. Прочитайте технічний рядок під картинкою: тепер він показує весь ланцюжок причин (наприклад, `RtspPlaybackException <- ... <- SocketException: ...`), а не лише «Source error». Перша спроба йде через RTP по TCP, друга дозволяє плеєру обрати транспорт (спочатку UDP); обидві записуються в журнал рядками `[LIVE]`.
2. На екрані Probe (меню з трьома крапками → Probe) натисніть Connect, потім **RTSP trace**. Застосунок запустить превʼю і запише в журнал усю розмову з камерою по RTSP (рядки `[RTSP]`: OPTIONS, DESCRIBE з SDP, SETUP з кількома варіантами адреси, PLAY і скільки медіа-кадрів надійшло за 3 с).
3. Натисніть Share log і надішліть текст. За бажанням додайте Logcat застосунку з фільтром `RtspClient|ExoPlayer|ExoRtspPlayer`.
Відомий ризик: у відповіді камери по RTSP некоректний заголовок `Content-Base: rtsp:///live/`. Якщо Media3 зупиняється з помилкою RTSP/джерела, наступний крок — тест libVLC, а потім власний невеликий RTSP-клієнт.

## Правила вибору (після звіту)
- Картинка за 5 с і затримка менше 1,5 с: лишаємо Media3.
- Картинка є, але затримка більша за 1,5 с: спробувати менші буфери, потім порівняти з libVLC.
- З Media3 картинки немає: спробувати libVLC; якщо і він не працює — написати власний RTSP-клієнт (OPTIONS, DESCRIBE, SETUP по TCP, PLAY) і декодувати H.264 через MediaCodec.

## Формат звіту
Версія Android; результат юніт-тестів (кількість із `app/build/test-results/testDebugUnitTest/*.xml`); таблиця M1–M10; що перевірено на телефоні, що лише тестами, а що зовсім не перевірено.
