# План тесту 0.3.3

1. Відкрий Пряму трансляцію, вийди, зайди в Налаштування камери. Перевір: трансляція не заважає, налаштування самі завантажуються, стандарт відео активний.
2. Почни запис відео, зайди в Налаштування. Перевір: є повідомлення, що камера записує, налаштування не завантажуються, внизу кнопка "Зупинити запис". Натисни її: запис зупиняється, налаштування самі завантажуються.
3. Disconnect, натисни "Обрати Wi-Fi і підключити": відкривається список Wi-Fi, після вибору мережі камери додаток підключається.
4. Share log.
