# План тесту 0.3.3
1. Увімкни Пряму трансляцію, вийди, відкрий Налаштування камери: рядки активні одразу (коротке перепідключення), кнопки «Розблокувати» немає. Зміни стандарт відео.
2. Запусти запис відео (кнопка на екрані трансляції), відкрий Налаштування камери: повідомлення і кнопка «Зупинити запис відео». Натисни її: список завантажується сам.
3. Disconnect. Перемкни телефон на іншу Wi-Fi мережу. Натисни «Підключитись»: відкривається системний список Wi-Fi; обери мережу камери, повернись: підключено.
4. Телефон уже в Wi-Fi камери, натисни «Підключитись»: підключається одразу, без списку.
5. Share log.
